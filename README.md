# Gamificação no Ensino de Algoritmos: Estudo de Caso e Proposta Beecrowd

Apresentação de slides em um único arquivo HTML (HTML, CSS e JavaScript puros, sem bibliotecas externas), desenvolvida para o componente curricular **Gamificação** do Instituto Federal de Sergipe (IFS).

O trabalho analisa o Beecrowd, uma plataforma de programação competitiva, usando o framework **MDA** (Mecânicas, Dinâmicas e Estéticas) e a **Teoria do Fluxo**, e propõe a adoção do seu modelo no ensino de algoritmos.

## Estrutura

```
Apresentação-Gamificação/
├── index.html
├── README.md
└── images/
    ├── Tela de Login.png
    ├── Perfil-top16.png
    └── Rank-IFS.png
```

## Como abrir

1. Mantenha o `index.html` no mesmo nível da pasta `images`.
2. Abra o `index.html` no navegador (dois cliques) ou use o Live Server do VS Code.

As imagens usam caminhos relativos. Ao mover o projeto, copie a pasta inteira.

## Controles

| Ação | Como |
| --- | --- |
| Próximo slide | Seta `→`, `Espaço`, `PageDown` ou botão na tela |
| Slide anterior | Seta `←`, `PageUp` ou botão na tela |
| Primeiro / último slide | `Home` / `End` |
| Tela cheia | `F` |
| Ir direto a um slide | Clique nos indicadores no topo |

Em telas sensíveis ao toque também é possível deslizar o dedo para os lados.

## Detalhes técnicos

- Proporção fixa de 16:9, escalada para qualquer tamanho de janela, sem barras de rolagem.
- Tema escuro inspirado em editores de código, com cor primária roxo Beecrowd `#5e219c`.
- Numeração de página no canto inferior direito em todos os slides, exceto na capa.
